# Israel Prison Service Data Analysis (שירות בתי הסוהר)

פרויקט ניתוח נתוני שירות בתי הסוהר (שב"ס) לשנת 2024.

## תכולת הפרויקט
- מחברות מחקר וניתוח נתונים ב-Jupyter Notebook:
  - `ips_analysis.ipynb` - ניתוח דוחות הכלואים הרבעוניים.
  - `ips_prison_boundaries_analysis.ipynb` - ניתוח גבולות ומיקומי מתקני כליאה.
- קובצי נתונים (דוחות רבעוניים 2024 וגבולות מתקנים).
- הנחיות ומסמכי מטלה.
